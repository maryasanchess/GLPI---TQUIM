RELATÓRIO DE OCORRÊNCIAS EM EXCEL (GLPI)
=========================================

O QUE FAZ
- Busca todos os chamados de uma entidade no GLPI (via API de busca) e gera
  um arquivo .xlsx formatado, com os campos nativos do chamado e os campos
  personalizados do plugin Fields.
- Não altera nada no GLPI: é só leitura.

ANTES DE USAR
1. Copie config_exemplo.json para config.json e preencha api_url, app_token
   e user_token.
2. Instale a dependência: pip install openpyxl
   (em servidores com Python gerenciado pelo sistema, pode ser necessário
   pip install --break-system-packages openpyxl, ou usar um ambiente
   virtual)
3. Ajuste a constante ENTITY_OCORRENCIAS e a lista PLUGIN_COLUMNS no topo
   do script para a entidade e os IDs de campo do seu GLPI (os IDs de
   campo do plugin Fields aparecem em Configurar > Listas suspensas, ou
   via /listSearchOptions/Ticket na API).

COMO USAR
    python exportar_relatorio_ocorrencias.py [caminho_saida.xlsx]
Sem argumento, salva na pasta atual com o nome
Relatorio_Ocorrencias_AAAAMMDD_HHMM.xlsx

AGENDAR EXECUÇÃO AUTOMÁTICA (mensal, em um servidor Linux sempre ligado)
1. Crie um cliente de API dedicado a essa automação em
   Configurar > Geral > API (restrinja o IP permitido ao próprio
   servidor, separado do cliente usado para uso interativo).
2. Copie o script e o config.json para o servidor (ex.: ~/relatorio_ocorrencias/)
   e restrinja a permissão do config.json: chmod 600 config.json
3. Adicione ao crontab (dia 1º de cada mês, às 8h):
     crontab -e
   e acrescente a linha:
     0 8 1 * * cd /caminho/para/relatorio_ocorrencias && /usr/bin/python3 exportar_relatorio_ocorrencias.py >> relatorio.log 2>&1

OBSERVAÇÕES
- O token de API (app_token) e o token pessoal (user_token) só são
  exibidos uma vez, no momento em que são gerados/regenerados na
  interface do GLPI. Não é possível recuperá-los depois — nem pelo banco
  de dados, nem pela API.
- O script não envia e-mail nem faz upload do arquivo gerado; ele só
  salva localmente. Para distribuição automática, seria necessário
  integrar com um servidor SMTP à parte.
